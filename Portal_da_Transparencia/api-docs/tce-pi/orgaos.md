# Órgãos

## Lista dados consolidados de Receita e Despesa de um Órgão em um Exercício

`GET /:idUnidadeGestora/:exercicio`

**Parâmetros:**
- `:idUnidadeGestora` - ID do órgão
- `:exercicio` - Ano do exercício

**Nota:** Este endpoint está na raiz da API, sem prefixo.

---

## Lista todos os Órgãos do Estado do Piauí em um Exercício

`GET /orgaos/lista/:exercicio`

**Parâmetros:**
- `:exercicio` - Ano do exercício
